# 电梯轿厢独立宣传屏实现与验收

## 定位与边界

本版本把工程包装为“基于安路 FPGA 的电梯轿厢离线宣传与应急信息屏”。它是独立 HDMI 显示节点：不接管电梯安全回路，不向电梯控制器发送运行控制命令，也不宣称具备商用电梯认证。楼层、方向、门状态和告警数据只用于演示顶部状态栏，数据来源可以是上位机 UART 或本地演示开关。

保持原工程的 640×480 输出、TF 卡预置图片、HDMI 音频、默认静音、字幕和音轨可视化。第一版不引入操作系统、网络协议、800×600 输出、大型 FFT 或运行时缩放。

## 资源与地址

日常宣传页为 `PIC1.BMP`～`PIC4.BMP`，紧急页为可选 `PIC5.BMP`。每张图统一为 640×480、24 位 RGB、无压缩 BMP；bank 地址按 32 位字计数：

| 区域 | 起始地址 | 用途 |
| --- | ---: | --- |
| bank0 | 0 | PIC1 |
| bank1 | 307200 | PIC2 |
| bank2 | 614400 | PIC3 |
| bank3 | 921600 | PIC4 |
| bank4 | 1228800 | PIC5 紧急页 |
| 缩略图缓存 | 1536000 | 四格日常缩略图 |

5 个图片 bank 加 1 个缩略图页共 1,843,200 个 32 位字，小于当前 2M×32 SDRAM 容量。PIC5 不参加四格缩略图；电梯模式按 `PIC5→PIC1→PIC2→PIC3→PIC4` 优先装载紧急页，普通媒体模式保持原来的 PIC1→PIC5 顺序。若告警发生时 PIC5 尚未加载，则显示逻辑生成的红色备用页。

## UART 演示协议

串口保持 115200、8N1、无流控，命令以 CR、LF 或 CRLF 结束。原有 `SUB=` 字幕命令继续有效。电梯命令如下：

```text
ELEV=F05,D=U,DO=C,A=0
ELEV=FB1,D=S,DO=M,A=1
ALERT=ON
ALERT=OFF
ELEV?
```

其中 `F00`～`F99` 和 `FB1`～`FB9` 是楼层，`D=U/D/S` 是上行/下行/停止，`DO=O/C/M` 是开门/关门/未知，`A=0/1` 是普通/告警。协议路由器统一消费接收字节，避免字幕解析器和电梯解析器同时报错；非法命令返回 `ERR ELEV`，不覆盖上一条有效状态。上电尚未收到有效楼层帧时显示 `F--` 和 `SIGNAL LOST`；收到合法帧后保持最后一次有效楼层，直到下一条合法帧或复位。

像素域只在帧边界提交 UART 状态。`ALERT=ON` 的优先级高于轮播和手动切图，播放器锁定日常图片选择并请求 bank4；`ALERT=OFF` 后进入恢复状态，在下一帧恢复告警前的日常图片和自动/手动模式。

## 状态和启动行为

电梯显示控制器包含 `STARTUP`、`NORMAL`、`ALERT`、`RECOVERY`、`FAULT` 五个状态：

- `STARTUP`：TF/SDRAM 尚未准备好时显示 FPGA 生成的启动图案，顶部仍显示楼层、LOAD 和计时；
- `NORMAL`：四张日常图按既有轮播、按键、字幕和音轨逻辑运行；
- `ALERT`：告警页或逻辑备用页在帧边界切换，暂停普通轮播；
- `RECOVERY`：告警清除后等待一次完整帧，再恢复之前的日常图片和模式；
- `FAULT`：TF、写 CDC 或资源错误时保持可见的故障图案，并通过 OSD 错误码/细分码说明原因。

顶层参数 `ELEVATOR_DEMO_MODE` 默认 0。设为 1 可固定进入演示；也可在运行时用 SW2=0、SW3=1 进入电梯演示。演示模式下 SW4 是独立本地告警开关，普通媒体模式下 SW4 仍是原有测试音入口。SW2=1 时进入参数服务界面，SW3 仅选择亮度/对比度，不会误触发电梯模式。此设计使原媒体播放器和电梯演示共用同一个 bitstream 逻辑，而无需替换图片链路。
