# 圆角选择器与垂直间距修复

日期：2026-10-29。按用户截图，仅优化楼层演示的选择器、展开菜单和纵向布局，不更改串口协议或楼层演示业务逻辑。

## 修改

- 起点、终点和单程/往返改用 `RoundedSelect`，选择框与按钮采用一致的 11px 逻辑圆角、标准 16px 字体、中性深灰背景和轻描边；去除原生直角下拉箭头槽及选中文本白底。
- 弹出列表采用圆角面板，选项行高 36px，圆角悬停/选中背景，保留绿色选中标记。支持鼠标、方向键、Home/End、Enter、Esc、Tab；点击外部、失焦、禁用、主题重建及销毁时释放弹出窗口和输入捕获。
- 演示区标题与选择行留白 8～10px，选择行与操作按钮间距 10～14px，进度线与说明另留 6～12px；按钮与选择器统一 38px 高度。
- 根据字体及子控件的真实请求高度分配演示卡高度。矮窗口适度收敛顶栏、告警带与状态行间距，为操作区和日志区保留空间；保留原字体尺寸及按钮点击面积。
- 保留暖白/中性深灰主题、DPI 缩放、演示中锁定路线和所有既有串口交互。

## 验证

- `test_host_display.py`：5 项通过。布局覆盖 1280×860@100%、1920×1080@100%、1800×1025@125%、2400×1260@125%/150%、截图同尺寸 2560×1349@125%。检查控件未裁切、行间距不低于 10px、标题间距不低于 8px、说明下方边距不低于 16px。
- 新选择器交互覆盖 100%、125%、150%、200% 缩放，验证菜单绘制、鼠标/键盘选择、Esc 取消、禁用关闭、点击外部关闭、销毁后无变量回调/输入捕获残留。
- `test_host_app.py`：41 项通过；`test_rescue_receiver.py`：8 项通过；总计 54 项。入口自检与 Python 编译检查通过。
