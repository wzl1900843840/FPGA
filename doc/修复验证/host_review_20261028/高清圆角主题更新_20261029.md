# 梯间守望上位机：高清圆角与双主题更新

更新日期：2026-10-29。范围为上位机显示与布局，串口协议、调度、告警生命周期和 FPGA 源码不在本次修改范围。

## 1. 当前外观

- 两套主题：暖白 `paper` 与中性深灰 `graphite`，默认深灰。旧偏好 `ink` 自动映射到深灰。
- 深灰主背景 `#181818`、表面 `#1D1D1D`、卡片 `#242424`；底色使用等值 RGB，去除原墨蓝色偏。暖白主背景 `#F4F4F0`、表面 `#FAFAF7`。
- 主按钮使用中性前景填充；绿色用于在线/有效状态，红色用于告警，琥珀色用于超时/异常/已确认但仍有效的告警。
- 主卡片圆角 18、诊断面板圆角 16、按钮圆角约 11 个逻辑像素；页签改为圆角选中块。没有位图放大或模糊滤镜。
- 统一中文和数字字体，放大楼层、主要操作及正文，保留常驻告警带与醒目的人工确认按钮。

## 2. 清晰度修复

诊断记录：旧进程 DPI awareness 为 0，系统向程序报告 2048×1152；启用 per-monitor-v2 后，本机报告原生 2560×1440，DPI 为 120，即 125%。原先系统位图缩放是模糊的重要原因。该记录用于解释修复依据，不等同于最终截图验收。

新增 `tools/host_app/display.py`，在创建 Tk 根窗口前启用 Windows DPI awareness。字体、Canvas 图形、间距、表格和鼠标命中统一按 96 DPI 逻辑坐标转换，在最终物理像素大小直接绘制。使用显式控件适配器，没有全局替换 Tkinter 类。

基准窗口为 1800×1000 个逻辑像素；最小设计尺寸为 1240×820 个逻辑像素。窗口按实际屏幕自动限幅，较短窗口缩小楼层数字并隐藏次要轨迹/日志说明。主控制卡片保留足够高度，启动计时及专家测试页增加垂直滚动。小窗口事件表可见行数会减少。

面向 1920×1080 与 2560×1440 的桌面使用。下列自动检查覆盖指定窗口和缩放；不将所有屏幕、缩放组合或跨显示器移动视为已验收。

## 3. 保持的交互与修复

- Ctrl+T 或状态栏色片切换主题；F8 切换投屏/诊断；F11 切换全屏。
- 切换主题保留手动楼层、方向、门状态、当前页签、轨迹和事件/串口缓冲，工作线程不会重复创建。
- 告警时普通控制禁用；确认按钮区分等待、发送中、已发出、设备已确认；收到回执不等于告警解除或救援到场。
- 修复目标楼层提示的垂直裁切并缩短文案；修复清空/重建后的空事件提示居中。
- 修复按钮按下时混色比例反向的问题，避免按钮瞬间过暗。

## 5. 启动与人工检查

关闭旧上位机窗口，重新双击工程根目录 `start_console.cmd`，使进程级 DPI 设置生效。选择 SIM 内置模拟设备即可离线检查。

建议依次查看深灰/暖白、普通/投屏、启动/专家页滚动、模拟告警、人工确认、设备回执与模拟解除。核对中文边缘、圆角、完整文字和告警醒目程度。当前最终外观仍需要这一步人工视觉复核。
