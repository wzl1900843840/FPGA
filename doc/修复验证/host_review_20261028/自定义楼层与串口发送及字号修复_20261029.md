# 自定义楼层、原始串口发送与字号修复

日期：2026-10-29。范围仅为 Python 上位机与相应测试；未打开 COM18、未烧录 FPGA，实板联调尚待完成。

## 使用方法

关闭旧上位机窗口，重新运行根目录 `start_console.cmd`，连接设备后等待有效状态回读。

- 楼层演示：选择 1～5 层中的不同起点与终点，选择单程或往返，再点击开始演示。2→5 自动上行，5→2 自动下行，2↔4 在区间内往返。默认仍为 1↔5。修改选择本身不写串口。
- 每个演示步按 2 秒推进；上一目标未得到匹配的楼层及方向回读时保持等待，不跳层、不追赶补发。终点先显示运行方向，下一步同层停止，因而相邻楼层也可展示上下行。单程在终点停止回读落实后显示“已到达”；往返在端点停靠后换向。
- 运行或暂停期间锁定路线选择。修改路线需先停止。告警与链路异常保留暂停机制，解除告警后仍需人工继续。继续以回读楼层为依据，区间之外不能直接恢复。
- 原始串口页：底部新增 TX 输入框和发送按钮，支持 Enter 发送、↑ 取回上次已接受的输入。自动追加 CRLF，最多 40 字节单行可打印 ASCII。禁止中文、换行、控制字符和超长输入；不支持十六进制或多行发送。
- 可发送 `ELEV?`、`RESCUE?`、`BOOT?` 等查询，或固件支持的单行控制命令。扩展命令是否支持以真实设备 RX 回包为准。查询保持演示运行，普通原始控制命令暂停演示。
- 告警有效时保留查询、匹配当前事件编号的 `ACK=xxxx` 以及显式 `ALERT=OFF`。普通原始写入受到告警保护。ACK 复用原有告警生命周期并优先调度，不自动解除告警。
- 调度“已排队”与真正的 TX 写出分开显示；TX/RX 继续写入现有日志。串口仍由唯一工作线程拥有，离线和历史回放禁止发送。

## 字体原因与修复

现场读取控件字体发现，原下拉框实际为 `TkTextFont`（Microsoft YaHei UI，9 pt）；仅配置 ttk 样式字体未改变其实际字体选项。

起点、终点、单程/往返及串口选择框现在显式指定 `(T.UI, T.F_LABEL)`，与界面标准控件一致：16 px 逻辑字号，100% / 125% / 150% 缩放分别为 16 / 20 / 24 px 物理字号。起终点标签同步统一字体，数字及模式居中。弹出列表复用现有统一字体设置。调整演示卡和串口区域留白，保证新增控件完整显示。
