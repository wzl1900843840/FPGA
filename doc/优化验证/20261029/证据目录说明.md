# 证据目录说明

本目录记录2026-10-29全链路优化。不同验证层级分别签收，所有截图均需按来源理解。

| 文件或目录 | 用途 |
| --- | --- |
| baseline.json | 修改前Git状态、外部压缩包及哈希 |
| stage1_tests | 三缺陷修复版本A的29项便携回归；与最终增强版本分开 |
| stage1_candidate | A的原始时序/资源/源哈希；可回退候选 |
| final_tests | 最终回归与顶层/厂商模型日志；portable_summary及fast_boot/summary必须全部通过 |
| font_gate_audit.json | 4096个RTL字与8块mapped BRAM INIT全量比对，包含源/网表哈希 |
| 中文菜单_宽松布局.png | 当前生产BRAM菜单分支RTL逐像素仿真预览，非实板照片 |
| final_candidate | 完成发布门禁后的最终物理报告、构建日志和validation.json |
| rejected_candidates | 失败或中止的候选报告，以及新增断言在旧源码上的预期失败日志 |
| evidence_manifest.json | 最终源码提交、BIT路径/哈希、源哈希与证据文件哈希 |
| 全链路自审与交付.md | 已实现内容、实际结果、残留边界与Git关系 |
| 构建与板上验收.md | 构建入口、控件表、三分钟演示、实板签收步骤 |

BIT保留在独立build_out候选目录；不覆盖用户既有src/td_project下的历史best_result。最终下载前以evidence_manifest.json及validation.json共同核对。没有hardware_tested:true的签收记录时，不能将仿真/STA通过称为实板验收通过。

F因setup失败被拒绝；G因仍存在异域复位到保持链D路径且局部route冲突而中止；H因发现最低水位统计重新预填充缺陷而中止。stage2早期试验文件移到build_out/history_stage2_tests_20261029，不混入正式通过证据。源码生成类一次性脚本存放doc/migration_scripts/fullchain_20261029，扩展名historical.txt，非生产入口。
