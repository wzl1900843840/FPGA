### D02 控件与交互收拢

- [ ] 全按键/拨码消抖、共用低速CE、统一优先级及完整控制真值表。
- [ ] 按已确认映射实现：SW1滚动字幕、SW2参数、SW3音频波形、SW4本地告警，职责固定。
- [ ] SW3只控制真实PCM波形图层，不影响音频；电梯为默认展示主题，不再占用场景开关或隐藏组合键。
- [ ] 覆盖全部16种拨码组合、帧边界提交及告警前后恢复；必要告警不被SW1/SW3屏蔽。
- [ ] 普通页K2下一张、K3自动/手动及长按上一张；K4短按静音/恢复、长按缩略图。
- [ ] 参数页前四项K2/K3增减、K4选字段、长按默认；随后提供只读诊断、二次确认重载。缩略图K2/K3移动、K4确认/长按取消。
- [ ] 参数页采用六项可见OSD菜单：明确选中框/箭头、字段名、实际当前值/单位、逐项按键提示和未保存状态；每次进入从亮度开始，K4只切焦点，最后一项循环回亮度。无需操作者数按键次数。
- [ ] 组合保存全释放可重入，长按不补短按，模式切换取消旧按压。
- [ ] 待执行翻图单槽+BUSY反馈；参数与动作跨域使用一致模式版本。
- [ ] 保存亮度/对比度/周期/记忆音量，兼容旧记录；启动手动静音且可一次开声。
- [ ] 告警先抢占、清除源独立、恢复正常图与自动状态。
- [ ] 告警音不受普通媒体静音屏蔽；SW4解除不等于远端告警或ACK状态自动清除。
- [ ] 图层切换不取消按键；页面切换取消旧按压和普通待执行翻图；三键同按拒绝执行且不误保存。
- 门槛：全部控制组合有预期结果，基础两键演示仍成立，无隐式上电诊断入口。

### D03 全链路可靠性

- [ ] reader错误/细节整份快照帧提交；事件与状态传递区别处理。
- [ ] SDRAM刷新、busy、长返回延迟下验证授权等待、FIFO水位和underflow。
- [ ] 启动/文件/共享事务有界等待，超时有可见状态与恢复出口。
- [ ] 每个超时给出计数时钟、期限计算依据、停止/排空/重建动作和测试；自动重建最多一次，持续故障保留备用页并允许手动重载。
- [ ] 必要共享重建时全部客户端/控制器协调，失效缓存，备用图独立运行。
- [ ] 无卡、坏BMP、缺PIC5、单图、文件截断、有限坏链、无ACK/陈旧楼层验证。
- [ ] UART优先兼容旧命令，文本启停不能绕过SW1物理总开关；处理ACK窗口与过期数据，不虚构自动热插拔或旧协议跨复位完全防重放。
- 门槛：故障后HDMI时序持续；能继续操作或有明确有界重载途径，不靠反复全局复位遮掩。

### D04 高分展示与轻量优化

### 主演示建议（约3分钟，具体用时以实测为准）

1. 全拨码0冷启动，展示独立读图；K4一次开声，此时波形关闭，确认声音独立正常。
2. K2下一张展示转场/换音；K3一次自动轮播，再按停止。
3. SW1打开滚动字幕，SW3打开真实PCM波形；K4长按进入缩略图，K2移动、K4确认。
4. SW2打开参数，K2/K3调节、K4切换前四字段，SW2关闭即回播放；诊断/媒体重载和保存放补充片段。
5. 展示明确的两分辨率对比素材，不在主流程换卡耽误操作；必要时独立短片。
6. SW4直接触发/解除本地告警；恢复原媒体及当前SW1/SW3图层状态。ACK/坏图/保存/冷启长测放补充证据。

主流程无需输入串口文本或启动PC模拟；可选UART现场改字/ACK明确标为外部刺激与监视。所有“实测”“通过”字样仅在对应验证确实完成后写入。
