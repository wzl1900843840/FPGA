## 2. 冻结的控制与显示规则

| 控件 | 职责 | 可见反馈 |
| --- | --- | --- |
| SW1 | 普通滚动字幕总开关 | 字幕出现/消失，关闭不删文本 |
| SW2 | 参数页开关 | 当前字段及K2/K3/K4操作提示 |
| SW3 | 最终PCM波形图层开关 | 波形出现/消失，声音连续 |
| SW4 | 本地应急告警源 | 应急页、提示音、来源与通信状态 |
| K1 | 全局复位 | 重新启动，SW4仍高则重新采纳告警 |
| K2/K3普通短按 | 下一张 / 自动手动 | 当前图号、切换/忙、AUTO/MANUAL |
| K3普通长按 | 上一张 | 不再补发自动切换 |
| K4普通短按/长按 | 静音恢复 / 进入缩略图 | 静音图标或缩略图焦点 |
| K2/K3缩略图短按 | 下一格 / 上一格 | 焦点移动，未就绪图不可确认 |
| K4缩略图短按/长按 | 确认 / 取消 | 回普通播放且只提交一次 |
| K2/K3参数短按 | 增加 / 减少 | 当前值及饱和边界 |
| K4参数短按 | 顺序选字段 | 亮度、对比度、音量、周期、诊断、重载 |
| K4参数长按 | 四参数恢复默认；重载项确认入口 | 默认值或重载确认层 |
| K2+K3保持3秒 | 保存持久化字段 | 保存中→已保存/无变化或明确失败 |

这里的“顺序选字段”是屏上可见菜单：六项名称同时显示，当前项有金色侧条及整行高亮底色，参数行显示实际值和单位，底部随焦点变化显示K2/K3/K4提示。每次SW2开启从亮度开始，K4短按只移动焦点，在重载项再次短按K4回到亮度；切焦点不改参数也不执行维护动作。调节即时生效，SW2关闭只退出菜单，不自动写Flash；未保存状态和显式保存反馈必须可见。

菜单示意，以下为推荐默认值而非当前实板读数：

    参数调节                         已修改/未保存
    > 亮度           255/255
      对比度         128（中性128）
      音量             0/255 静音
      轮播周期         5秒
      ────────────────
      诊断             只读
      重载媒体         需确认
    当前：亮度
    K2增加  K3减少  K4下一项  长按K4默认
    SW2关闭退出；K2+K3保持3秒保存

- [ ] 首次使用者仅看屏幕即能指出当前调节的字段、值和增减按键，不依赖背诵顺序。
- [ ] 六行名称与选中状态在SW1/SW3不同组合下均清楚，菜单不遮挡全部图片。
- [ ] K4六次短按循环回亮度，无任何参数被误改；两项维护操作不因单次短按直接执行。
- [ ] 画面/声音效果、已应用值、未保存标记与保存结果一致；应用中/失败不假报成功。

滚动字幕/波形是装饰层；状态、操作反馈、错误和应急说明不受其开关屏蔽。电梯是默认应用主题，不产生真实楼层；无数据显示未接入，过期显示过期，本地生成值标演示。

告警时K2/K3/K4不执行普通功能；告警音策略独立，普通静音不能屏蔽提示音。解除后恢复原正常图片及播放状态，参数页取当前SW2，字幕/波形取当前SW1/SW3。远端告警尚有效时，仅关闭SW4不能解除整个应急状态；ACK只确认接收。

## 5. 三缺陷与输入边界

| 编号 | 输入/故障 | 必须观察到的结果 |
| --- | --- | --- |
| F01a | 仅PIC1有效，手动NEXT/PREV | 原图保持可见，busy最终释放，不等不存在的index_commit |
| F01b | 仅PIC2、0图、加载中由1图变2图 | 无死等；0图备用；资源发布与按键交错结果确定 |
| F01c | 转场中自动开关/告警抢占 | 单槽有界，告警先接管；解除不回放旧普通事件 |
| F02a | 授权128字后每个发令位置注入换帧 | 当前事务完整闭合，owner释放，新帧可继续 |
| F02b | 延迟/刷新/busy、不同25/40MHz相位 | 返回不串帧、FIFO不溢出、不半复位 |
| F02c | 控制器不再返回 | watchdog走有限恢复或可操作故障页，不锁死全系统 |
| F03a | 完整双键保存、全释放、再次保存 | 产生两次合法保存；同次长按不连写 |
| F03b | 一键先松/一键未松/错峰按下 | 未全释放不重装；组合不会夹带单键 |
| K01 | 20ms抖动边界、999/1000ms长按边界 | 按稳定判据一次触发，长按不补短按 |
| K02 | 3秒组合边界、三键同按 | 组合按重叠时间；无效三键不保存/翻图 |
| K03 | SW2切页或告警时正在按键 | 旧动作取消至释放，无跨页双执行 |
| K04 | SW1/SW3切换时正在按键 | 不改变按键归属或声音，不误取消普通动作 |
| K05 | 重载确认/取消，重载时再重载/保存 | 未确认可取消，接受作业仅一次，互斥时BUSY |
| K06 | Flash保存中调参数/重复保存/告警 | 字段冻结并提示；告警不被Flash忙阻塞 |

- [ ] 修复断言必须在旧源码上失败、新源码上通过；保留旧“REPRODUCED”日志但不改写为PASS。
- [ ] 原26项回归保留；若接口调整，旧测试按明确的新需求更新，不删除原覆盖来换通过率。
- [ ] F02所有位置至少含授权同拍、首字、返回并发、中间、末字、drain和连续帧请求；随机用例记录seed。

## 7. 参数、反馈和资源目标

| 字段 | 默认/调节 | 保存与重启 |
| --- | --- | --- |

- [ ] LUT≤90%与像素关键setup≥0.5ns只是争取目标，失败不以假约束补齐。

- [ ] 无功耗仪表则只报告结构/活动率结果；数字降亮度不等于显示器背光节电。

## 8. 实施批次与候选保护

1. 阶段0保留工作区用户改动，生成可恢复快照与哈希，不覆盖旧候选。
2. 阶段1只修三缺陷，复现→修复断言→既有回归→隔离候选A。

5. 阶段5冻结源副本、独立构建候选B；源副本与报告/位流一致，避免junction指向后续修改。

每阶段交付：修改清单、可复跑命令、测试摘要、失败与剩余项、源/位流哈希；首次/最终候选附实际STA/资源。计划本身不估未经测量的构建工期。
