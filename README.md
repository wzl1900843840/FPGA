## 当前状态

2026-10-09 完成 SD 正常读取 6.25→12.5 MHz、首张有效图片校验并写入排空后提前显示，以及后台图片加载/缩略图构建共享 SDRAM。音轨面板新增平滑连线、渐变包络、背景网格和峰值保持音量柱。初始化仍保留 100 ms 上电等待和 390.625 kHz 慢速时钟。

音轨底板/网格保留 87.5% 原照片，包络/柔光保留 75% 原照片；状态、参数、计时统一字形，文字带一像素深色阴影。参数显示实际周期（毫秒精度），字段变化后预计算数字并在帧边界提交。

此前实板已确认图片显示、切图、自动轮播、HDMI 音频、亮度/对比度、字幕滚动计时和旧音频波形正常。新版的启动耗时、不同 TF 卡兼容性与长期稳定性尚需实板验收。UART 命令需追加 CRLF。
